# DevOps with Docker: Security and Optimization

Course submission repository for Fall 2026.

- Exercise 3.1: `3_1/` contains the Express application and a Compose setup
  with Watchtower. `.github/workflows/publish-express.yml` publishes its image.
- Exercise 3.2: `3_2/` contains Docker Quick Reference. The workflow
  `.github/workflows/deploy-render.yml` publishes the image and triggers Render.
  The deployed app is https://docker-quick-reference.onrender.com.
- Exercises 3.3 and 3.4: `3_3/` and `3_4/` contain the builder scripts.

The remaining exercise directories are part of the official course template.
